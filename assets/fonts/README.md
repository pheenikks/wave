Bundled typefaces, each under the SIL Open Font License 1.1 (see the matching
`OFL-*.txt`). They come unmodified from https://github.com/google/fonts.

Anton, Archivo Black, Bebas Neue, Caveat Brush, DM Serif Display,
Instrument Serif, Montserrat, Space Grotesk, Space Mono

Montserrat is included as three fixed weights (Medium, SemiBold, Black) cut
from the variable font with fontTools, because Qt does not pick a weight from
a variable font on its own.
